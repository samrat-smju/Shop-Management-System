# Shop Management System

A responsive shop inventory and sales dashboard built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with product count, stock units, revenue, and low-stock alerts
- Add, edit, and delete products
- Search products and filter stock status
- Cart and checkout with stock validation
- Sales history and CSV export
- Browser localStorage persistence
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Deployment
This is a static site. Publish the repository root on Netlify with no build command and `.` as the publish directory.

## Data note
The application stores its data in the current browser's localStorage. Data is not shared between devices or browsers, and clearing browser storage can remove it.
